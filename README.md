# Iris Classifier

Hello World ML project using the Iris dataset.

## What's inside
I have explored the classical models under the classification task under machine learning. I have explored different model families under classification to show the different capabilities of these classical Machine Learning models that are there from the baseline model as the logistic model building up to the other families that can handle the non linear relationships and the complex feature relationships.
- Data exploration (pairplots, distributions)
- Data quality checks and cleaning
- Discussion on why certain choices were made during the EDA 
- Logistic Regression classifier
- KNN classifier
- Random Forest

## Setup

To run this project, install the required libraries:

pip install -r requirements.txt


This installs numpy, pandas, matplotlib, seaborn, and scikit-learn (latest versions).
